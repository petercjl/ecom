Ecom Agent 插件

让当前使用的 Agent 读取 Ecom 账号信息，并按授权使用指定账号的会话请求后台数据。插件包含命令行工具和配套 Skill，由 Agent 完成安装与更新。

支持列出账号、查看登录状态与已保存首页，以及读取已启用来源的 HTTPS JSON 接口。请保持 Ecom 运行；当前浏览器连接支持 macOS。后台取数需先核验对应店铺身份。
