# 小红书 CLI 搜索验收

日期：2026-11-05。范围：macOS arm64 Ecom Dev、npm 能力包源码及本机 Codex 管理安装。

## 可用能力

`ecom-cli xhs search --container VALUE --keyword VALUE --via page --json` 在指定小红书原生容器中创建临时后台搜索标签，网站使用该容器的现有会话生成搜索请求；浏览器从实际搜索结果 DOM 提取首屏最多 20 条笔记，返回 ID、标题、作者、展示点赞数及不含会话参数的规范链接。命令固定实例和容器，校验关键词与返回内容，支持结构化错误及非零失败退出码。

浏览器仅执行内置的固定提取代码，不接受任意脚本、站点 URL 或凭证输入。CLI 要求显式 `--via page`；无此选项的请求不会默默回退为页面导航。浏览器通过 Dev 端点的 `xhsPageSearchProtocol:1` 声明兼容能力。

原生隔离世界只读 DOM，网站正常执行搜索及签名，当前没有抓取网络 JSON 或移植逆向签名库。Cookie 由容器持有，手机号验证码登录不影响已建立会话的复用。

## 真实取数证据

- 开发入口搜索“收纳”，得到 18 条匹配关键词的真实笔记结果。
- 产品 CLI 源码入口搜索“手工钩针抱枕”，得到 18 条结果；标题包括“玫瑰花抱枕，真的太美了！（附图解）”和“💛奶油玫瑰抱枕｜附图解”。
- 执行真实 npm pack、在隔离前缀安装产物，并通过包管理命令同步当前 Codex 的 CLI 运行时和 Skill，SHA-256 核验 current=true，保留恢复副本。
- 通过同步后的 CLI 入口再次取得相同关键词的 18 条结果。原始结果仅保存到本地私有测试文件，未打入 npm 包或 Git。
- 原生改动通过统一 build-dev 脚本编译及正常重启；普通有界面模式，无 CDP、调试端口、调试管道或独立 Chrome。

临时搜索标签在成功后、仍处于后台且未被用户导航到其他页面时请求关闭；`pageClosed` 通过 WebContents 生命周期核对关闭结果。用户主动选中或导航过的标签保留。登录、验证及超时时保留页面，返回具体状态。

## 自动验证

npm 包测试 37 项通过；开发 CLI 测试 5 项通过；配套 Skill 格式及可移植性检查通过。测试覆盖显式模式、参数边界、实例／容器固定、错误来源、关键词匹配、重复笔记和带凭证参数链接拒绝。npm 更新测试使用独立的作用域仓库配置，以免用户 npm 配置影响模拟注册表。

## 适用边界

已验收的是页面辅助取数，页面会临时加载到后台标签。完全不加载平台页面的 Cookie-only 搜索尚未通过，见 [Cookie 请求对照](xhs-session-probe-2026-11-05.md)。这两种模式不能混淆。当前只读取首屏；分页、评论、笔记详情及经过平台接口证明的账号身份尚未接入。此能力当前要求匹配的 Ecom Dev；正式版与 Windows 仍需各自构建和验收。源码版本尚未通过 npm 公共渠道发布。
