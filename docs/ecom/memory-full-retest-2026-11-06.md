# 全部合格后台页自动休眠复测（2026-11-06）

同一 Ecom Dev 实例、原有 7 个标签，5 个合格后台业务页全部由自动调度休眠。总 physical footprint 中位数 **1591.78 → 412.44 MiB**，减少 **1179.34 MiB（74.09%）**；进程数 **15 → 9**，渲染进程数 **9 → 3**。

测试后已恢复 **20 分钟**自动休眠设置。5 个业务页保持休眠，全部标签、6 个保存账号及原容器归属保留；原来的内存页和另一个窗口的新标签页保持选中。没有测试用保持运行例外。

## Ecom 同实例前后对照

| 阶段（北京时间） | 内存中位数 | 5 次采样范围 | 进程数 |
| --- | ---: | ---: | ---: |
| 全部加载，自动休眠关闭，15:17:11–15:18:12 | 1591.78 MiB | 1575.34–1883.92 MiB | 15 |
| 5 个后台页自动休眠，15:21:46–15:22:47 | 412.44 MiB | 412.44–412.64 MiB | 9 |

本轮“前”是当前二进制关闭自动休眠、全部原标签加载后的基线；“后”是同一二进制和实例开启自动调度后的结果。两阶段之间没有重启，标签标题、origin、位置、窗口、容器及选中状态一致。每阶段 5 次完整采样，间隔约 15 秒。动态页面在基线期间仍有 GC／缓存变化，范围已完整列出；没有强制 GC、清缓存或关闭业务标签。

自动休眠阶段临时使用 60 秒阈值，执行前保留所有编辑、任务、媒体及原生资格保护，每 30 秒最多一页。原生动作记录核对了 5 次成功卸载与导航保留；没有手动卸载、强制执行、按站点放行或人为排除合格业务页。休眠对象为天猫商家中心、生意参谋和 3 个小红书搜索页。它们在本轮均无编辑／取数／媒体保护理由；两个选中的内部页保持运行。

最早 P0 前的记录为 1858.64 MiB，当前休眠后相对该记录低 **77.81%**。该值仅作跨时点参考：前台、运行时长、缓存及动态内容不同；本轮同实例策略效果以 **74.09%** 为主要结论。

这组数据回答当前桌面上各浏览器实际占用多少。Chrome／Brave 保持各自已有的标签、会话、扩展、使用时长及策略；未为它们复制 Ecom 的相同网页，也未获取其精确实时标签数和有效 Memory Saver 状态。因此这些总量不构成同等网页负载下的浏览器效率排名，不能把它们与 Ecom 的差额全部归因于实现优劣。Ecom 是组件 Dev 构建，Chrome／Brave 是商业发布构建。

| Ecom 进程类别 | 全部加载中位数 MiB | 自动休眠后中位数 MiB |

| GPU | 127.67 | 95.35 |

网页渲染进程是主要下降来源；主进程和公共服务继续驻留。各类别单独取中位数，与总量的中位数不是严格可加关系。保留的 3 个 renderer 不等同于 3 个运行中的业务标签。

## 测量与运行条件

- macOS 26.5.2（25F84），Mac16,7，24 GiB，14 个逻辑 CPU。Ecom Dev 156.1.98.0、Chrome 156.0.8078.80、Brave 155.1.97.59；构建工作树和实例元数据见 JSON。
- 所有浏览器均通过 `proc_pid_rusage(RUSAGE_INFO_V0)`，按主进程后代归组并对唯一 PID 累加，未连接浏览器调试入口。独立系统计量与 Ecom 原生快照的 10 次 PID 集合全部一致；连续采集的总量最大差为 0.4375 MiB。
- Footprint 包含压缩内存等记账，不等于 RSS、JS 堆或系统去重后的物理 RAM。脱离主进程树的 crashpad 未纳入，进程采样不是原子操作。
- 完整有效轮次期间存在后台 macOS Release 编译；已核实该入口不重启 Dev，复用它持有的工作区重启互斥保护，并对每个快照校验相同实例／主 PID／标签清单。此前被另一轮 Dev 重启打断的试采保留为历史证据，未参与上述统计。
- 本轮仅执行测量及可恢复的自动休眠配置，未修改浏览器源码、清理会话或干预其他浏览器。测试结束恢复 1200 秒设置，用户访问休眠页时在原容器重新加载。
