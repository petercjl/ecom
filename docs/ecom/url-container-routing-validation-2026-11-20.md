# 网址打开规则：macOS Dev 实施与验收

日期：2026-11-20。此记录对应用户确认的 URL → 指定容器方案及内置淘宝／天猫示例。功能入口为账号管理中的“网址打开规则”。本轮修改已进入源码；不发布 npm 或正式浏览器版本。

## 已实现

- Profile 本地规则、顺序、全局和单条启用状态；GUI 与认证本地 CLI 共用原生读写、匹配及版本冲突校验。
- 内置可编辑的淘宝／天猫商品详情示例，包含 item.taobao.com 和 detail.tmall.com 的 /item.htm 路径及非空 id 参数条件。目标容器留空，规则默认关闭；选择容器后仍需用户手动开启。
- 精确网址、域名／路径通配、可选子域及查询参数条件；支持多条条件、批量粘贴、复制、排序、删除和零网络请求测试。
- 顶层 HTTP(S) 请求与重定向阶段选择目标容器，跨容器创建独立标签并保留来源页面；不传递 opener、认证头或 POST 数据。跨容器表单、失效目标和循环路由停止处理。不同目标的推测性预渲染直接取消，后续实际导航按普通规则处理。
- 既有会话恢复保留原容器；页面子资源和原生网络请求保持原有归属。显式页面任务冲突时阻止切换；商品采集标签保持固定容器。
- CLI 源码命令为 routing list / inspect / save / delete / reorder / test / set-enabled；浏览器声明 urlRoutingProtocol=1。配套 canonical Skill 与机器能力清单已更新，当前公共 npm 仍未发布这些变更。

1. 原生匹配单元测试 4 项通过：示例关闭和留空、启用必须选目标、域名边界、大小写／末尾点、编码与重复查询参数、路径、精确网址片段、全局开关及优先级。
2. CLI 功能／包测试 53 项通过，覆盖真实认证文件信箱、新旧协议拒绝、配置修订号与未知变更结果；其中既有测试也覆盖本地打包、隔离安装与更新。历史已发布版本的升级回归另列限制，未算入通过数。
3. 项目脚本回归 41 项通过；新增批量网址表单模型测试 2 项通过，验证替换空白占位条件、保留已有草稿、非法输入和数量边界。
4. canonical Skill 格式、可移植性、能力合同及 generic 适配检查通过。属于本机验证，未执行用户未要求的隔离 Agent 回归。
5. 已使用真实 Ecom Dev 和认证原生能力回读：示例存在、enabled=false、containerId 为空、条件数为 2；测试淘宝详情 URL 仅报告关闭的示例，不产生网络请求或有效目标。
6. 真实原生配置回归：创建未分配且关闭的临时规则，测试精确网址片段匹配，拒绝无目标启用和旧修订号写入，最后删除本轮临时规则。回读确认原有规则和全局开关保持一致。
7. 原生增量构建及普通无调试端口的 Dev 重启已成功；过程复用既有 Component_arm64 输出及完整缓存。打包 CLI 含新增 routing 模块，源包的版本／Skill 一致性检查通过。

原始回读、备份、临时安装和构建记录位于本机忽略提交的 .brave-build/url-routing-lr7sd3px/ 与对应 dev-restart-* 中；用户账号与机器信息不进入本报告或 npm 包。

## 验收边界

- 计算机 UI 检查因当前浏览器地址不允许计算机操作而终止；本轮未声称界面目视验收通过，也未用其他 UI 自动化方式绕过限制。
- 真实淘宝／天猫登录后的点击、后台标签／弹窗／短链、HTTP 请求 Cookie 身份以及 Windows 原生运行仍需分别验收；匹配和配置检查不替代这些证据。页面自身的后台抓取、预取等子资源请求不在主导航重路由范围内。
- 完整 npm 历史升级回归中，既有已发布 CLI 在临时 npm 安装阶段超时，本轮停止了该测试树；这项遗留兼容证据未通过。新 routing 功能测试通过不等于公共发布或历史升级链全部通过。
- 当前只更新源码与 macOS Dev，没有修改 Ecom 正式版，也没有发布或同步其他 Agent。
