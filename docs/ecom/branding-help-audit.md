# Ecom 帮助与品牌入口检查（2026-11-06）

下一轮正式构建：Windows x64 0.1.6、macOS arm64 0.1.3，包含原生更新菜单提醒和本次帮助入口替换。两个平台独立版本、构建和发布；构建完成后先验收 next，稳定提升单独核实。

本次替换的桌面入口：

- 帮助菜单、快捷键及设置页帮助链接使用离线内置 `ecom://ecom-help/`；内容涵盖浏览、店铺容器、下载、更新恢复、权限、保护及问题反馈。
- “关于”页的产品名称和版本链接使用 Ecom，更新错误帮助与说明链接进入本地指南。
- 设置中的容器、WebRTC、Cookie、权限、保护规则等说明链接使用 Ecom 帮助；版本说明不再拼接上游版本号为外部发布地址。
- “反馈问题”进入本地反馈说明，联系内部维护人员；不调用上游 Webcompat 提交功能。
- 站点内容设置气泡、导入和硬件权限等帮助链接进入 Ecom 帮助。

分类保留：代码符号、兼容协议、源码来源、版权和许可证维持真实身份；Brave Search 如作为实际搜索服务，其域名属于第三方来源。Shields 过滤订阅和安全服务端点按功能用途保留，本次只替换帮助与产品入口。已裁剪的 Tor、钱包、Leo 等模块源代码中的上游链接不作为桌面可见入口，未进行无差别字符串替换。

CLI 审查：新帮助页面为只读内置导航，不增加管理权限或网页消息处理器；完整 CLI 的通用导航和帮助入口仍为分期缺口。更新状态与安装操作的 CLI 缺口继续按更新提醒说明记录。

验证以统一 Mac Dev 构建、原生帮助页实际打开及 Windows/macOS 正式产物为准。Windows 更新菜单与帮助的完整桌面验收仍需下一轮 next；源码扫描不代表所有平台界面已目视通过。
