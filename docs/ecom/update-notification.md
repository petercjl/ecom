# Ecom 原生更新提醒

更新程序将实际更新状态传给浏览器，复用 Chromium/Brave 的原生工具栏更新提示及菜单顶部入口。文案使用 Ecom。

| 状态 | 菜单顶部入口 | 点击结果 |
| --- | --- | --- |
| 有可用版本 | Ecom 更新… | 打开更新界面，由用户选择下载 |
| 正在下载和校验 | 正在下载更新… | 重新显示后台下载状态 |
| 已校验并准备完成 | 重新启动以更新 Ecom | 再次核验已准备载荷，通过后正常退出并安装 |
| 当前渠道无更新 | 无更新提示 | 保留原有菜单 |

下载完成后可继续工作，准备状态持续保留。Windows 沿用下载、稍后、重启、独立安装进度、回滚与自动清理机制。macOS 的暂存载荷随更新程序生命周期管理，关闭所属浏览器后清理。原生通知连接有效时，发现更新和准备完成通过菜单提醒；用户主动打开的下载、错误及安装界面继续显示。

共享状态层只负责呈现与命令分发，更新程序负责版本、来源、完整性和安装授权。Windows 使用当前用户和 SYSTEM 可访问的随机命名事件，状态事件与退出事件分开；macOS 使用绑定浏览器进程、应用路径和随机令牌的分布式通知。只有准备完成的明确重启操作可以触发安装，更新程序仍执行载荷核验和正常退出校验。

当前产品 CLI 尚未开放更新状态、下载、重启及回滚命令；后续应复用同一更新能力及授权校验。维护自测入口不属于产品 CLI。
