# 商品页手动规则跳转

## 行为与责任

启用的淘宝商品规则指向有效买家容器时，商家、买家和普通标签中的匹配商品页都可显示“按照规则跳转”。图库去重后仅有 1–3 张主图，或出现明确的“访问异常提示”时，显示原生提示条。安全验证保留平台原页面。商家访问他店商品遭到平台明确拒绝时，继续自动进入既有买家流程。

浏览器复用已加载页面的图库与提示，展示按钮后停止检查。按钮触发时重新核对当前文档、商品 URL、规则和目标账号，提取商品 ID，在指定买家容器内按标题搜索，核对搜索结果的商品 ID 并加载可显示的详情。搜索失败时显示现有错误状态。已到达目标买家账号的商品页同样可手动查找，搜索结果标签不会重复弹出本次提示。

原生提示条负责用户交互，规则解析与买家查找复用现有浏览器能力。规则更改时撤销现有提示，关闭规则后停止观察；固定了账号的 Agent 任务保留其会话边界。

## CLI 契约审查

现有 CLI `routing list/test/enable/disable` 与提示条复用原生配置和规则校验。配置变化通过原生偏好订阅立即撤销提示条。URL 预览仍表示规则匹配，不表示已观测到页面不完整。

当前新增按钮是原生 UI 操作；CLI 尚无针对具体标签的手动规则跳转命令，此项明确保留为能力缺口。没有扩展网页脚本权限或把 CDP 作为正式版功能实现。

## 验收边界

macOS Dev 验收包含受控三图页面、原生按钮操作、规则关闭撤销、完整图库及真实买家跳转。受控页面仅验证交互与分支，不能代替淘宝真实受限响应的证据。Windows 和正式发布包另行验证。本轮不发布 npm。
