# Ecom CLI：Lumyne scope 与网页打开规则

日期：2026-11-20。候选包为公开包 `@lumyne/ecom-cli@0.4.0`，拟用稳定渠道 `latest`。本记录描述本机候选验证，公共注册表发布单独确认。

## 能力与使用

浏览器保存规则并负责匹配、容器校验和并发修订号；CLI 提供可组合操作；配套 Skill 将用户的网址范围、目标容器和启用意图转成配置。普通用户可以向当前 Agent 发送：

> 使用 Ecom CLI，把淘宝和天猫商品详情页设置为用“买家账号”容器打开，并启用这条规则。

命令包括 `routing list / inspect / save / set-container / enable / disable / delete / reorder / test / set-enabled`。指定容器保留原匹配条件和开关；启用／停用仅修改单条规则开关。写入要求最新修订号。目标支持稳定 ID 或唯一精确名称；重名、缺失目标和并发修改返回明确错误。本地匹配测试不访问网站。全局开关与单条规则开关分别报告。

## 包迁移

新包的安装、更新检查、运行时路径、能力清单和 Skill 身份统一使用 `@lumyne/ecom-cli`。旧包保留既有发布历史；旧 updater 仍查询旧 scope。通过新包的 `skill migrate --from-package @petercjl/ecom-cli` 显式迁移当前 Agent 的准确目标，核对归属与文件哈希，保留完整恢复备份，再激活目标独立拥有的运行时。普通安装不会覆盖旧包目标，本地修改和无主目标受到保护。

本机只迁移 Codex 的受管理 Skill 与独立 CLI 运行时。其他 Agent 与独立 npm 全局 bootstrap 保持原状；后续调用使用迁移回执指定的新运行时。浏览器账号、会话和既有规则由浏览器持有。
