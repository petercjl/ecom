# 关于 Ecom 的版本与更新显示

“关于”页从当前安装的原生发布元数据读取发布版本、npm 包名及渠道。macOS 使用当前应用的 Info.plist；Windows 使用安装目录的 ecom-update.json。元数据在后台线程读取并在当前页面处理器中缓存，不读取账号数据。无发布身份的 Dev 显示开发版本与本地构建更新说明。

更新按钮调用已有 Ecom 更新能力，与帮助菜单共用下载、校验、用户确认及重启流程。页面显示该能力提供的可用、下载、待重启状态；无上述状态时显示“更新由 Ecom 独立更新器管理”，不将空闲状态误报为“已是最新版本”。最新版本结论由独立更新器实际检查后提供。页面每两秒刷新进程内状态，隐藏或离开页面后不继续请求；刷新本身不发起网络检查。

产品名称、许可证产品说明和帮助链接使用 Ecom；上游版权、第三方许可证及 Chromium 引擎版本保留真实信息。

CLI 审查：本次复用现有更新能力，不新增后台更新权限。发布元数据、更新状态与人工确认的更新操作尚未提供稳定产品 CLI 命令，列为后续缺口；浏览器 version 与 CLI 包版本是不同身份。

验收范围：本轮先构建和验证 macOS Dev；正式包的发布版本/更新来源展示与 Windows 运行验收分别记录，不能以 Dev 验证替代。
