# Ecom 界面品牌文字

浏览器自身的菜单、提示条、设置和窗口标题统一使用 Ecom。GRIT 构建在已完成翻译查找后替换品牌文字，中文及其他语言共享规则，保留源消息、翻译指纹与资源 ID。规则位于 `chromium_src/tools/grit/grit/tool/build.py`。

这使现有中文提示“Brave 使用完全隐私的产品分析来估计某些功能的整体使用情况”输出为“Ecom 使用完全隐私的产品分析来估计某些功能的整体使用情况”。原有功能和用户设置保持原有语义。

规则处理拉丁品牌词在中文中的相邻书写、英文大小写和占位符。版权、许可证、条款及来源主体保留原名；HTML 属性、实际 URL、邮件地址、命令行开关和兼容性标识保留原值。源码中的 Brave 类名、路径、资源符号和翻译文件继续承担内部兼容与来源记录。

实验功能页面中直接以 C++ 字符串提供的 89 处显示文字同步使用 Ecom，实验开关 ID 保持原值。其他网站自身的内容不在此规则内。

构建前检查：

```sh
python3 -B -m unittest script.lib.l10n.ecom_branding_test
```

提交源码后通过 `node ecom/build-dev.mjs` 增量编译并重启 Dev。界面核对以实际编译的语言包和运行页面为准。
